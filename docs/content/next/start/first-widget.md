## The intended flow

This is the design. It is not built.

1. Open the Widget Center with a shortcut key or the bar icon.
2. Pick a widget in Discover. The card lists the data it asks for before you install.
3. Install it. The install pins a commit, so you get the code that was reviewed.
4. The widget appears in the first free slot on the desktop. Drag it, resize it, or change its variant.
5. If it needs data that includes a secret, you approve the grant and store the secret in the vault.

Removing a widget from the desktop keeps it installed with its settings.

See [Browse and install](/docs/next/start/browse-and-install/) for how to read a widget's page before installing, and [Set up a widget](/docs/next/use/set-up-a-widget/) for data and grants.

## What you can do today

To see the chain work, follow [Try it safely in 10 minutes](/docs/next/start/try-it-safely/). It installs three widgets into a throwaway folder and draws them offscreen. To make a widget instead of using one, use the [guided builder](/make/), or read [Choose a path](/docs/next/create/choose-a-path/).
